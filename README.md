# 우리동네 국·공유재산

> 구민주권 행복도시 서구
>
> **찾고, 확인하고, 서식까지 국·공유재산을 한곳에서!**

대전 서구의 국유·시유·구유 재산 정보를 한 지도에 모아, **구청은 재산 현황을 한눈에 보고 정책을 판단하고**,
**주민은 우리동네 재산과 신청 서식·접수처를 스스로 확인하는** 서비스의 **기획 랜딩 페이지**입니다.

## 기획 방향

1. **행정 정책지원** — 행정동별 국·시·구유 분포, 활용 가능 재산, 재산관리관을 지도와 숫자로 바로 봅니다. 대장을 내려받아 다시 세지 않고 유휴재산 활용·매각 계획을 판단합니다.
2. **민원인도 한눈에 확인** — 필지 정보와 도면을 보고, 재산 종류에 맞는 신청 서식과 접수처를 한곳에서 확인합니다.

국유는 중앙관서·한국자산관리공사, 시유는 대전광역시, 구유는 서구 부서가 각각 접수합니다.
그래서 온라인 접수를 하나로 묶지 않고 **맞는 서식과 내야 할 곳을 정확히 안내**하는 방향으로 기획했습니다.

## 핵심 기능

| 기능 | 쓰임 | 내용 |
|---|---|---|
| 재산 현황 한눈에 | 정책지원 | 행정동별 국·시·구유 분포와 건수, 활용 가능 재산 |
| 재산 조회·도면 | 행정·민원 공통 | 지번, 지목, 면적, 소유자, 사용·대부 현황, 토지이용계획, 지적도·위치도·현황도 |
| 신청 서식·접수처 | 민원 안내 | 국유재산 서식 8종, 구유재산 서식 7종, 재산별 접수처 |
| 활용 가능 재산현황 | 행정·민원 공통 | 지금 빌리거나 살 수 있는 재산 모아 보기 |

## 사용자

- **구청 (정책지원)**: 현황 파악 → 유휴재산 선별 → 활용 계획 검토 → 부서 공유·민원 응대
- **주민·민원인**: 검색 → 정보 확인 → 서식·접수처 확인 → 담당 부서에 신청

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 랜딩 페이지 구조와 문구 |
| `architecture.html` | 기획의도와 시스템 구조도 (`/architecture`) |
| `style.css` | 디자인, 반응형(PC·태블릿·모바일) |
| `script.js` | 첫 화면 지도, 화면 미리보기 데모(필지 선택, 도면 전환, 서식·접수처 안내), 사용자 탭 |
| `data/seogu-jaesan.json` | 서구 시유·구유재산 동별 건수와 활용 가능 시유재산 55건 |
| `forms/` | 신청 서식 한글 파일 15종 (국유재산법 시행규칙 8종, 대전광역시 서구 공유재산 관리 조례 시행규칙 7종) |
| `docs/` | 기획 설계서, 구현 계획서, 세부페이지 설계서 |

빌드 과정 없이 `index.html`을 브라우저로 열면 바로 볼 수 있습니다.

## 자료

첫 화면 지도의 시유·구유 건수는 [대전광역시 재산정보 공개시스템](https://www.daejeon.go.kr/jaesan/PropertyList.do)의
**2026년 4월 기준 실제 자료**입니다(서구 시유 2,415건, 구유 3,600건).
필지 위치는 예시이며, 국유는 [e나라재산 국유재산포털](https://www.k-pis.go.kr/addMapView.do) 연계 전이라 예시로 표시했습니다.

신청 서식은 법령 별지 서식이며, 법령이 바뀌면 국가법령정보센터의 최신 서식을 확인해야 합니다.
시유재산 서식은 대전광역시 규칙을 따르므로 이 사이트에 싣지 않고 문의처만 안내합니다.
