# 우리동네 국·공유재산

> 구민주권 행복도시 서구
>
> **흩어진 국·공유재산을 한곳에, 신청까지 원스톱!**

대전 서구 안의 국유지·공유지 정보를 조회하고, 사용(대부)허가·매수 신청까지 한 페이지에서 처리하는 서비스의 **기획 랜딩 페이지**입니다.

## 핵심 기능

1. **재산 조회**: 지번, 지목, 면적, 소유자(국유/공유), 사용·대부 현황, 토지이용계획(용도지역·지구, 토지이음 열람 연결)
2. **온라인 서류 신청**: 사용(대부)허가 신청서, 매수신청서, 사용(대부)허가 포기서
3. **활용 가능 재산현황**: 지금 빌리거나 살 수 있는 땅 모아 보기
4. **도면 보기**: 지적도(경계·모양), 위치도(주변 도로·건물 속 위치), 현황도(지금 땅이 쓰이는 모습)

## 사용자

- **주민·민원인**: 검색 → 정보 확인 → 서류 작성·제출 → 처리 결과 알림
- **구청 담당 공무원**: 신청 접수 → 검토 → 허가·반려 → 재산현황 자동 갱신

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 구조와 문구 |
| `style.css` | 디자인, 반응형(PC·태블릿·모바일) |
| `script.js` | 화면 미리보기 데모(필지 선택, 지적도/위치도/현황도 전환), 사용자 탭 |
| `docs/` | 기획 설계서, 구현 계획서 |

빌드 과정 없이 `index.html`을 브라우저로 열면 바로 볼 수 있습니다.
