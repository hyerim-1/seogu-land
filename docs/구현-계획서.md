# 「우리동네 국·공유재산을 한눈에」 랜딩 페이지 구현 계획서

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 서구 국·공유재산 조회·신청 서비스 기획서를 정적 랜딩 페이지로 만들어 GitHub에 올리고 Vercel로 배포한다.

**Architecture:** 빌드 없는 정적 사이트. `index.html`(구조·문구), `style.css`(디자인 토큰·레이아웃·반응형), `script.js`(데모 필지 선택·도면 전환·사용자 탭·스크롤 등장 효과) 세 파일. 데모 지도는 인라인 SVG, 예시 데이터는 `script.js` 안의 배열.

**Tech Stack:** HTML5, CSS3(커스텀 속성, Grid/Flex), 바닐라 JavaScript(ES2020), Google Fonts, Git, GitHub, Vercel

**Spec:** `docs/기획-설계서.md`

## Global Constraints

- 슬로건 문구 그대로: `구민 주권, 행복 도시 서구`
- 서비스 이름 그대로: `우리동네 국·공유재산을 한눈에`
- 서류 이름 그대로: `사용(대부)허가 신청서`, `매수신청서`, `사용(대부)허가 포기서`
- 도면 = `지적도`, `위치도` 두 가지
- 기획자 표기: `서구청 토지정보과 윤혜림`
- 하단 고지: `AI 교육 실습용 기획안이며 현재 운영 중인 서비스가 아닙니다. 화면의 재산 정보는 예시입니다.`
- 통계·수치를 지어내지 않는다. 기대효과는 "목표" 표현만 사용
- 외부 JS 라이브러리 없음, 빌드 도구 없음
- 375px 폭에서 가로 스크롤 없음, 콘솔 오류 없음
- 디자인: 연한 베이지 바탕, 초록 포인트, 지적도 격자 패턴
- `seogu-land/` 폴더만 저장소로 사용 (상위 폴더의 `.env` 등은 절대 포함 금지)
