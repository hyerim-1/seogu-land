# 설계서: 「우리동네 국·공유재산을 한눈에」 기획 랜딩 페이지

- 작성일: 2026-09-15
- 기획자: 서구청 토지정보과 윤혜림
- 목적: AI 교육 실습 과제 — 만들고 싶은 프로그램의 기획서를 랜딩 페이지로 제작 → GitHub 업로드 → Vercel 배포

## 1. 소개할 프로그램

대전 서구 내 국유지·공유지 정보를 조회하고, 관련 서류 신청까지 한 페이지에서 처리하는 서비스.

- **사용자**: 주민·민원인(조회·신청), 구청 담당 공무원(접수·검토·관리)
- **슬로건 / 이름**: 구민 주권, 행복 도시 서구 · 우리동네 국·공유재산을 한눈에

## 2. 디자인 방향

- 분위기: 지도·토지 느낌 — 연한 베이지 바탕, 초록 포인트, 지적도 격자 패턴
- 공공서비스다운 정돈된 레이아웃으로 신뢰감 확보
- 모바일(약 400px)에서도 한 열로 자연스럽게 보이도록 반응형

## 3. 페이지 구성 (위 → 아래)

1. **첫 화면(Hero)** — 슬로건(작게), 서비스 이름(크게), 한 줄 설명
   "국유지·공유지 조회부터 사용(대부)·매수 신청까지 한 페이지에서", 동네지도 일러스트
   - 드론이 서구청에서 출발해 활용 가능 필지 2곳을 차례로 날아가 촬영 조사하고 복귀하는 반복 애니메이션
   - 조사 상태 표시(드론 현황조사, 고도, 진행 필지 수)와 필지별 "조사 완료" 표시
   - 움직임 줄이기 설정 사용자에게는 조사를 마친 정지 화면 제공
2. **왜 필요한가요?** — 불편 3가지 카드
   - 정보가 여러 곳에 흩어져 있음
   - 신청하려면 구청을 직접 방문해야 함
   - 담당자가 대장·신청서를 수작업으로 관리함
3. **핵심 기능 4가지**
   1. 재산 조회 — 지번, 지목, 면적, 소유자(국유/공유), 사용·대부 현황, 토지이용계획(용도지역·용도지구·용도구역 등)
      - 데모: 정보 카드에 예시 값 표시 + 토지이음(eum.go.kr) 토지이용계획 열람 페이지를 새 창으로 여는 버튼
      - 실제 서비스: 브이월드·공공데이터포털의 국토교통부 토지이용계획 공개 API로 필지별 자동 조회(토지이음 화면 수집은 하지 않음)
   2. 온라인 서류 신청 — 사용(대부)허가 신청서, 매수신청서, 사용(대부)허가 포기서
   3. 활용 가능 재산현황 — 지금 빌리거나 살 수 있는 땅 모아 보기
   4. 도면 보기 — 지적도(경계·모양), 위치도(주변 도로·건물 속 위치), 현황도(지금 땅이 쓰이는 모습, 네이버·다음 지도의 항공사진 현황에 해당)
4. **화면 미리보기(체험 데모)** — 가상의 필지 지도에서 필지 클릭 → 정보 카드 표시,
   카드 안에 [지적도 | 위치도 | 현황도] 전환 버튼과 서류 신청 버튼. "예시 데이터" 표시 필수
   - 현황도는 지도 API 없이 직접 그린 그림(위에서 내려다본 모습)으로 표현하고 "그림으로 표현한 예시"임을 표시
   - 실제 지도 화면 캡처는 저작권·이용약관 문제로 사용하지 않음
5. **누가, 어떻게 쓰나요?** — 탭 전환
   - 주민: 검색 → 정보 확인 → 서류 작성·제출 → 처리 결과 알림
   - 공무원: 신청 접수 → 검토 → 허가/반려 → 재산현황 자동 갱신
6. **기대 효과** — 민원 방문 감소, 처리 기간 단축, 유휴재산 활용 증가 (수치는 "목표"로만 표현, 지어낸 통계 금지)
7. **개발 계획** — 활용 데이터(국유재산 공공데이터, 서구 공유재산 대장), 기술 구성,
   로드맵(1단계 조회 → 2단계 신청 → 3단계 관리자 기능)
8. **하단(Footer)** — 기획: 서구청 토지정보과 윤혜림 /
   "AI 교육 실습용 기획안이며 현재 운영 중인 서비스가 아닙니다. 화면의 재산 정보는 예시입니다."

## 4. 기술 구성

- 순수 HTML + CSS + JavaScript (빌드·설치 없음)
- 파일: `index.html`, `style.css`, `script.js`
- 외부 라이브러리 없음. 웹폰트는 Google Fonts(Pretendard 대체 가능 폰트) 사용 가능
- 데모 지도는 인라인 SVG로 직접 그림 (실제 지적도 데이터 사용 안 함)

## 5. 폴더·배포

- 위치: `AI자율실습_2/seogu-land/` (기존 실습 파일·`.env`와 분리)
- 이 폴더만 Git 저장소로 만들어 GitHub에 업로드
- Vercel에서 GitHub 저장소를 가져와(Import) 정적 사이트로 배포 — 별도 설정 없음
